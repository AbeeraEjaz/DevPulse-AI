# 🌐 DevPulse AI: Socio-Economic Policy Simulator & HDI Forecasting Engine

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://devpulse-ai.streamlit.app)
[![Built for UNDP Analytics](https://img.shields.io/badge/UN-Development%20Framework-006EB5)](https://www.undp.org)
[![Author](https://img.shields.io/badge/Author-Abeera%20Ejaz-0A66C2)](https://www.linkedin.com/in/abeera-ejaz-0b287a316)

DevPulse AI is an interactive, data-driven machine learning application that leverages **World Bank Open Data** to analyze multi-dimensional development indicators across 260+ nations. Built with the **UNDP Human Development Index (HDI)** methodology, it empowers policy researchers and international development teams to simulate the impact of socio-economic interventions.

---

## 🚀 Key Features
- **Global Indicator Analytics:** Automated ETL pipeline consuming World Bank APIs across Education, Health, Digital Adoption, and Energy metrics.
- **Explainable AI (XAI) Priority Engine:** Random Forest & Gradient Boosting models to rank policy levers based on direct mathematical contribution to national development.
- **"What-If" Policy Intervention Simulator:** Real-time parametric sliders to forecast projected HDI improvements and GDP per Capita changes.
- **Executive Policy Brief Generator:** 1-click automated PDF generation for policy briefs.

---

## 🛠️ Tech Stack
- **Languages & Frameworks:** Python, Streamlit
- **Machine Learning:** Scikit-Learn (Random Forest, Gradient Boosting), Joblib
- **Data Engineering:** World Bank API (`wbgapi`), Pandas, NumPy
- **Visualizations:** Plotly Express & Plotly Graph Objects
- **Reporting:** FPDF2
